# Portfolio Resume

A personal portfolio and resume website for Nalinkumar R J, built as a responsive static web page to showcase projects, skills, education, certifications, and contact details.

## Overview

This project presents a modern portfolio landing page with sections for:

- introduction and profile summary
- featured project highlights
- skills and technologies
- education and certifications
- e-commerce design work
- contact and social links

The site is designed to be clean, minimal, and professional while highlighting both technical work and creative design experience.

## Project Structure

- `index.html` — redirects to the main portfolio page
- `resume.html` — main portfolio/resume page
- `assets/` — images and visual assets used across the portfolio
- `README.md` — project documentation

## Tech Stack

- HTML5
- CSS3
- Static asset-based design
- Responsive web layout

## Run Locally

You can open the site directly in a browser, or run a local server:

```bash
cd portfolio_resume
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
